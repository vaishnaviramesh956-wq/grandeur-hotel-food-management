# 🏨 GRANDEUR Hotel Food Management System

A full-stack Hotel Food Management System built with PHP and MySQL.

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Theme: Dark luxury with gold accent

## ✨ Features
- 🔐 Admin Login with session management
- 📊 Dashboard with live stats
- 🍽️ Menu Management (Add/Edit/Delete)
- 📋 Order Management (Pending/Preparing/Ready/Served)
- 🪑 Table Management
- 👨‍💼 Staff Management
- 📈 Reports & Analytics
